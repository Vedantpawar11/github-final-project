# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based project that calculates the simple interest on a principal amount using the rate of interest and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

* **Principal (P):** The initial amount of money.
* **Rate (R):** The annual rate of interest in percentage.
* **Time (T):** The time period in years.

## Usage

Run the Bash script and enter the principal amount, rate of interest, and time period when prompted.

The calculator will display the calculated simple interest.

## Example

Suppose:

* Principal = 1000
* Rate = 5%
* Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

The simple interest is 100.
